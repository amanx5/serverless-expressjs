# Serverless Express.js Hello World

Simple Express.js + Vercel example that returns a "Hello Express!" response.

Read docs: https://vercel.com/docs/frameworks/backend/express

To develop locally:

```
npm install
vc dev
```

```
open http://localhost:3000
```

To build locally:

```
npm install
vc build
```

To deploy:

```
npm install
vc deploy
```
